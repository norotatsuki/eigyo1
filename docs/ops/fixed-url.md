# 全社員に配る URL を固定する

社員に配れるのは「変わらない URL」だけである。今は変わる。その落差を埋める手順。

## 今どうなっているか

画面は既に外から見える。合言葉も効いている。ただし URL が仮のもので、
繋ぎ直すたびに別名になる。

```
12:28  → https://zen-nut-museums-cardiovascular.trycloudflare.com
16:56  → https://trinity-turning-brings-racing.trycloudflare.com
```

無料の仮トンネル (trycloudflare) の仕様なので、設定では消せない。
**cloudflared にログインして、自分の名前で開く**しかない。そのために
ドメインが 1 本要る。

## 会社ドメイン (p2c-produce.com) は使わない

使えないわけではないが、割に合わない。

```
NS: ns-cloud-e1..e4.googledomains.com   ← DNS を Google で運用中
MX: aspmx.l.google.com 他               ← 会社のメールが、その DNS に乗っている
```

Cloudflare の無料枠で名前を使うには、**ドメインのネームサーバーごと Cloudflare へ
移す**必要がある。つまり営業リストの画面ひとつのために、全社のメール経路を
移設することになる。写し漏れがあればメールが止まる。

→ **このツール専用のドメインを 1 本取る。** 年 1,500 円前後。会社ドメインには触らない。

## 手順

### 1. ドメインを 1 本取る (5 分)

Cloudflare のアカウントを作り、Registrar で好きな名前を取る。
社名と関係なくてよい。短くて打ちやすいものにする。

他所で取ったドメインでもよいが、その場合はネームサーバーを Cloudflare に
向ける (新規ドメインなので、何も乗っていない = 止まるものが無い)。

### 2. この Mac を、そのアカウントに紐づける (2 分)

```bash
cloudflared login
```

ブラウザが開く。1 で取ったドメインを選んで許可する。
`~/.cloudflared/cert.pem` ができれば成功。

### 3. 使う名前を決めて、書いておく (10 秒)

```bash
echo 'eigyo.取ったドメイン' > .public-hostname
```

`eigyo` の部分は好きに変えてよい。このファイルは git に載らない。

### 4. 待つ (最大 30 秒)

番人 (`scripts/keep-serving.sh`) が輪の中で毎回見に行くので、
2 と 3 が揃った時点で**自動的に張り替わる**。手で何かする必要はない。

確認:

```bash
cat .public-url            # → https://eigyo.取ったドメイン に変わる
tail -5 .keep-serving.log  # → 「固定の名前が使えるようになりました。張り替えます」
```

以降、繋ぎ直しても URL は変わらない。

## 社員への案内

| 渡すもの | 中身 |
|---|---|
| URL | `.public-url` の中身 |
| 合言葉 | `.serve-password` の中身 |

合言葉は全員で 1 つを共有する形なので、URL とは別の経路で渡す
(URL をチャット、合言葉は口頭など)。誰が入ったかは記録されない。
社員ごとに分けたい場合は別途仕組みが要る。

## 承知しておくこと

この画面は**この Mac が動かしている**。固定 URL にしても、次の間は繋がらない。

- Mac の電源が落ちている
- Mac が回線に出られていない (`.keep-serving.log` に「回線に出られていません」)

蓋を閉じても止まらないようにはしてある (`caffeinate -is`)。それでも
持ち歩けば切れる。切れない形にしたいなら、常時稼働のサーバーへ移すことになる。

## 元に戻す

```bash
rm .public-hostname
```

次の見張りで仮の URL に戻る (また変わり続ける状態になる)。
