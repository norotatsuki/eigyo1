# コメント行 (# 始まり) と空行は無視。
#

#   - 「一般的な日本人が理解しにくい横文字 / ジャーゴン」を対象

#     * 定着済み外来語: テスト / バグ / データ / ファイル / エラー / メール / ページ / 画面 / 情報
#     * 日常用語化した IT 語: パソコン / スマホ / ネット / アプリ / 動画 / 音声
#     * 固有名詞: TypeScript / Playwright / GitHub / Claude / macOS / npm / bash 等
#     * 数値・単位: 3 GB / 512 MB / 2.4 GHz
#     * 学術/専門用語で日本語代替が困難: JSON / YAML / API / URL / HTTP / SQL
#   - 明確な言換候補があるカタカナ語のみ禁止
#

# --- v1.2.0: 逃げ言葉 / narrow-scoping / defer / ジャーゴン ---
# 2026-07-26 事故: Claude が「narrow に scoping」「defer」「P0 完了」「別 session」等の
# アルファベット略語で報告を誤魔化し、手抜きを覆い隠したことへの対応。
# 一部の頻出用語 (JSON/API/URL/HTTP/SQL 等) は判定原則で除外済み。
defer	先延ばし	途中打切り検出係が「先送り」を禁止語に持つため衝突しない語を採用
scoping	対象範囲	範囲を狭めるアリバイ表現
narrow	狭める	範囲縮小の逃げ言葉
P0	最優先	優先度ラベルは日本語で書く
P1	次点	優先度ラベルは日本語で書く
P2	後回し不可	優先度ラベルは日本語で書く (P2 で defer するのは禁止)
TBD	未定	曖昧な逃げ言葉
TBA	未告知	曖昧な逃げ言葉
WIP	作業中	曖昧な逃げ言葉 (完遂責任の回避)
N/A	該当なし	arrow-verify で使用禁止済み (逃げ表現)
UC	使用場面	要件仕様書での「use case」略語
UUID	識別子	一意識別子の略語
verdict	判定	日本語で書く
arrow	矢印	日本語で書く
verify	動作確認	日本語で書く
context	文脈	日本語で書く (「context 切れ」等は defer 系逃げ言葉)
session	会話	tech context だが「別session で継続」等の逃げに悪用されやすい
narrow scoping	対象範囲を狭める	narrow-scoping ズルの直接表現
