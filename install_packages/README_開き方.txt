===================================================================
  CC AGI インストーラー — 開き方 (macOS)
===================================================================

【症状】
  「"CC_AGI_Installer.command" は開いていません」
  「Apple は …マルウェアが含まれていないことを検証できませんでした」
  という警告が出て起動できない。

【原因】
  macOS の Gatekeeper が、インターネット / AirDrop / 別 Mac 経由で
  受け取ったファイルに自動付与する「隔離属性 (com.apple.quarantine)」
  をチェックし、Apple 公証されていない .command を実行前にブロック
  しています。

  このインストーラー自体は安全ですが、Apple の公証を受けていない
  ため、初回のみ手動で許可が必要です。

-------------------------------------------------------------------
【方法A — 右クリックから開く (最も簡単)】
-------------------------------------------------------------------
  1. Finder で "CC_AGI_Installer.command" を選択
  2. 「control」キーを押しながらクリック (または 2本指クリック)
  3. メニューから 「開く」 を選択
  4. 出てくるダイアログで再度 「開く」 をクリック

  ※ macOS Sequoia (15) 以降ではこの手順が使えないことがあります。
     その場合は【方法B】を使ってください。

-------------------------------------------------------------------
【方法B — Terminal で隔離属性を解除 (確実)】
-------------------------------------------------------------------
  1. 「ターミナル」アプリを起動
     (Spotlight で "terminal" と入力 → Return)

  2. 以下を入力 (最後に半角スペース1つ)。まだ Return は押さない:

         xattr -cr

  3. Finder で解凍後のフォルダをターミナル画面にドラッグ&ドロップ
     (フォルダのパスが自動入力されます)

  4. Return を押して実行

  5. あらためて "CC_AGI_Installer.command" をダブルクリック

  例:
     $ xattr -cr ~/Downloads/CC_AGI_Installer_v20260715
     $ open  ~/Downloads/CC_AGI_Installer_v20260715/CC_AGI_Installer.command

-------------------------------------------------------------------
【方法C — システム設定から許可】
-------------------------------------------------------------------
  1. まず一度ダブルクリック (ブロックされる)
  2. 「システム設定」 → 「プライバシーとセキュリティ」 を開く
  3. 画面下部の
     「"CC_AGI_Installer.command" はブロックされました」
     の右にある 「このまま開く」 ボタンをクリック
  4. パスワード / Touch ID で認証
  5. あらためてダブルクリック

===================================================================
【補足】
  ・python3 がインストールされていない場合は先に:
        brew install python
    または https://www.python.org/downloads/ からインストール
  ・起動後、ブラウザ (127.0.0.1:17071) が自動で開きます
  ・ターミナルの黒い画面は閉じないでください (サーバー本体です)
